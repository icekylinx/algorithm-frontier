# Document formatting

Authored curation documents use fenced code blocks and `$$ ... $$` for every
displayed LaTeX expression. This keeps GitHub rendering consistent across the
problem summaries, proof maps, and verification indexes.

The files under `sources/` preserve imported research text and source bytes.
Their original `\[ ... \]`, `\(...\)`, or TeX conventions are not mathematical
edits to the source; the curation layer links to them without rewriting their
claims. New summaries use the repository convention above.
