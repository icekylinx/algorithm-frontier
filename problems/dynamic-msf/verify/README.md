# Verification and proof scope

The manuscript derives the public two-thirds envelope by
substituting a pruning contract into the stated deterministic weighted MSF
framework. This is a composed public-baseline bound; it is not presented as
a newly proved qualitative MSF algorithm.

The weak pruning contract, literal connectivity adapter, finite horizons,
weighted hierarchy and published changes are separate proof obligations.
The source/version comparisons are preserved in the dependency manuscripts.
No executable implementation of the full dynamic MSF framework is included.

Read the [main proof](../proof.md) with its [source map](../sources.md). Repository checks validate links, mathematical syntax and catalogue coverage; they do not certify the asymptotic theorem. No proof-assistant verification or external peer review is claimed.
