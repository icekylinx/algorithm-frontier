# Lower-bound scope audit

The R checkpoint records unconditional rank-oracle query boundaries. The S checkpoint additionally gives deterministic-ETH consequences for readable rank programs or circuits. These statements are separate:

- an oracle lower bound does not automatically apply to a readable explicit representation;
- a deterministic-ETH consequence does not exclude randomized algorithms without a randomized-ETH assumption;
- neither statement is a lower bound for every graphic, linear, or explicitly represented matroid class;
- support-budget classifications are worst-case statements under parameter upper bounds, not claims that every instance with the same numeric pair is equally hard.
