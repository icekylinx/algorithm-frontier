# Complexity-scope audit

The displayed bounds use the source-defined parameters:

- $$T$$ is the sum of numeric targets, not input bit length or inverse accuracy;
- $$Q$$ counts distinct nonempty eligible-column support patterns;
- $$d$$ is fixed row dimension;
- $$H$$ includes the binary input and paid polynomial primitive work.

The R and S records state their preprocessing, base-versus-independent-region scope, exact budget handling, and mandatory-total requirements. No support-sensitive bound is presented as a universal runtime independent of its representation or target regime.
