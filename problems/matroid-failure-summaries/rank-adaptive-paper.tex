\begin{abstract}
Fix a total order on an explicitly listed matroid of rank \(r\), with at
most one failure label per item. Let \(T\) be the sum of the numbers of
new canonical-basis items introduced by each individual label failure.
We construct one independent subset of the original canonical basis,
of size \(r-T\), whose contraction preserves every subsequent failure
query after reinserting the surviving contracted items. The identity holds
for every original order prefix, including rank drops. It reduces the
canonical-basis tree from rank \(r\) to rank \(T\), giving
\(O(N(r+T^h))\) independence queries for \(T\ge3\). We then give a
direct rank-two algorithm with \(O(N+h^2)\) queries and a matching
worst-case lower bound for computing the exact canonical union when
\(N\ge h+3\). At residual rank \(T=2\), the total query count becomes
\(O(Nr+(h+1)^2)\), with the sharp retained size \(r+2h\).
The rank-one residual requires only one input scan. An additional
all-label-budget endpoint uses \(N+r_U\ell\) queries at arbitrary rank.
No linear representation of the original matroid is assumed. Oracle calls
and ordinary computation have separate explicit bounds.
\end{abstract}
