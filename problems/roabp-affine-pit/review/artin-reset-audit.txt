1. The strongest concrete reset attack

Work in R=F[x,y]/(x^2,y^3), with active coordinate first and passive
coordinates 2,3,4. Let epsilon be zero or one and take

  A_1(x) = [ 1 0 x 0 ]       A_2(y) = [ 1       0 0 0 ]
           [ 0 1 0 x ]                [ y       0 0 0 ]
           [ 0 0 0 0 ]                [ epsilon*y 0 1 0 ]
           [ 0 0 0 0 ]                [ 0       0 y 0 ].

The constants have ranks two and two, while their full constant product
is P_1. Each local matrix has unit rank two. The full product has its
only potentially nonzero rows
  (1+epsilon*xy, 0, x, 0),
  (y,            0, xy,0).
Their indicated 2-minor is epsilon*x^2*y^2, which vanishes in R.
Its active pivot 1+epsilon*xy is a unit. Thus every interval has exactly
its asserted unit rank, including the full interval's unit rank one.

For epsilon=0 these ranks are already preserved over the polynomial
domain before truncation. For epsilon=1 the rank-one identity genuinely
uses x^2=0: its polynomial lift has the nonzero minor x^2*y^2. This
second case tests the full Artin theorem, which assumes an identity
inside the ring rather than a fraction-field rank. The certificate
records this distinction explicitly and does not present the epsilon=1
lift as an original rank-preserving polynomial example.

Start from B_0=e_1^T and passive p=e_2^T. The active output of B_0 over
the whole interval is 1+epsilon*xy and that of p is y. The prescribed
initial control is therefore
  a_0=-y/(1+epsilon*xy)=-y+epsilon*x*y^2.
It depends on the future variable y and, when epsilon=1, uses a
nontrivial nilpotent inverse. It belongs to the finite ring R; no
nonunit denominator is inverted.

After the x-layer, the controlled state is
  (-y+epsilon*x*y^2, 1, -xy, x).
It is manifestly not a polynomial in prefix variable x alone. After
the y-layer its entire output is zero. Direct multiplication verifies
both statements in Q and F_2, with the appropriate signs.

For this example the local normalized passive data are
  Ftilde_1 = [1 0 x; 0 0 0; 0 0 0],
  Ftilde_2 = [0 0 0; 0 1 0; 0 y 0],
  Z_1=(0,x,0),   Z_2=0.
The uncontrolled passive response is NOT zero:
  (1,0,0) Ftilde_1 Ftilde_2=(0,xy,0).
The reset is exactly the nontrivial identity
  (0,xy,0) = -a_1 Z_1 Ftilde_2,
where a_1=a_0 and Z_1 Ftilde_2=(0,x,0).
The extra future multiplier y shifts the scalar monomial from x to xy,
but introduces no new row direction: both coefficient spans are the
same one-dimensional passive direction.

The one-block source is the coefficient of x in B_0 A_1, namely e_3^T.
Restarting the ACTUAL suffix A_2 from span(e_1^T,e_3^T) keeps active
projection span(e_1^T), has positive passive constant rank one, and is
coefficientwise contained in the actual final reachable space. Thus the
specific same-width restart required by the proof is legal in this
nonzero-reset example, even in the ring-only epsilon=1 variant.

2. A smaller future-control example where the prefix span is proper

The previous example has a full four-dimensional prefix coefficient
span, so a second example checks that future controls do not enlarge a
PROPER prefix span. Again use F[x,y]/(x^2,y^3), now at width three:

  A_1=[1 x 0; 0 1 0; 0 0 0],
  A_2=[1 0 y; y 0 y^2; 0 0 1].

Both local ranks are two and their product has rank one, even before
truncation. Set B_0=e_1^T and p=e_2^T. The whole active pivot is 1+xy,
and the future-dependent control is -y/(1+xy)=-y+xy^2.
After the first layer the controlled row is
  (-y+xy^2, 1-xy, 0).

The actual prefix family from B_0 and p has coefficient space
span(e_1^T,e_2^T), a proper two-dimensional subspace. Every coefficient
of the controlled row stays in this subspace despite the occurrence of
future y and xy^2. Its passive remainder has coefficients in span(e_2^T),
the actual K_1. The final controlled output is exactly zero.

This example separates the two notions that might otherwise be confused:
the controlled polynomial need not be an actual prefix polynomial, but
its coefficient ROWS remain in the actual prefix coefficient space.
Only the latter property is needed by the dynamics and reset.

4. Why arbitrary future controls cannot escape the span

Let an actual row family M have expansion sum_alpha m_alpha M_alpha
in the fixed monomial basis of the FULL tensor algebra. A compatible
left multiplier U has expansion sum_beta m_beta U_beta. A coefficient
of UM is an F-linear combination of rows of the matrices U_beta M_alpha,
with the ring's scalar structure coefficients. It is consequently in
the span of the coefficient rows of M.

This statement does not require disjoint variables, positive degrees,
or that U use only prefix variables. Truncation may kill scalar products
of monomials but cannot invent a new row direction. If U is a matrix
unit, applying the same inclusion to U^{-1} gives equality of spans.
The statement is left-sided; arbitrary right matrix multiplication
would not preserve the row span, and is not used in the proof.

An actual prefix family can be embedded into the full tensor algebra
with all future exponents initially zero. Future multiplication changes
which monomials carry its row directions, not the span of those
directions. Thus a controlled intermediate state belongs to S_i tensor R
coefficientwise even when it does not belong to the prefix subalgebra.

Its active coordinates a_i are extracted using a constant field right
inverse of H. Subtracting a_i B_i is still coefficientwise in S_i,
because B_i is a field-constant reachable lift. The remainder has zero
active part coefficientwise and hence lies in K_i tensor R. Multiplying
the local projection identity pDEJH=pDE by arbitrary coefficients of
this remainder remains legal even when their variables overlap the
current local block. This proves the exact EV identities continue to
hold for controlled states.

6. Why the same-width restart is not circular

For fixed passive width k, first prove the POSITIVE-product case for
all word lengths, using only stable-phase theorems at widths k-q<k.
Only after that case is established is the ZERO-product case proved.
Its source suffixes have positive passive product, so invoking the
already proved positive case at the same k is not an invocation of
the unproved zero case. Word length is not an extra induction measure.
The palette refinement has the identical logic with strictly higher
active rank levels in place of smaller passive widths.

For each source coefficient p, the restart's initial space lies in
the actual reachable S_j. Propagating the unchanged suffix keeps all
its coefficient rows in the actual S_i. Its active projection is at
most T by this inclusion and at least T because constant propagation
of B_j supplies T. Hence it is EXACTLY T throughout. All interval
unit-rank hypotheses remain those of the same actual suffix matrices.

The restarted passive input is assigned weight one. Its suffix support
is therefore at most G-1, so reattaching its one original source block
costs at most G. The active input B_j costs zero relative to that stable
phase, with any previous global cost retained as the phase's offset.
The tight example above makes both charges explicit.

7. A nearby invalid example identifies the indispensable hypothesis

Over F[x]/(x^2), the matrix diag(1,x) has constant rank one but its
2-minor is the nonzero element x. Starting from passive e_2 gives
nonzero output x e_2 with zero active part. A purported reset based

This is NOT a counterexample: it fails the required unit-rank/vanishing-

future controls as low-support prefix polynomials, or applying the
induction to Ftilde words with an invented rank profile would be invalid.
The audited proof makes none of those moves.
