# Curated problems

Every completed problem directory follows this contract:

1. `README.md` — model, strongest supported bound, status, and caveats;
2. `proof.md` — selected current proof note with source path;
3. `verify/` — at least two independent/root audits or executable checks;
4. `sources.md` — exact source map and attribution footer.

A result is not promoted to this directory merely because it has a better
number. The model, comparator, parameter, assumptions, and additive terms must
match. Older same-scope claims are omitted from the current directory and stay
in the preserved checkpoint snapshots or an explicit historical module.
