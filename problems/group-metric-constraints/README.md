# Finite-group, affine, and metric sparsification

One nonnegative coefficient per original generator, constraint, metric, or block preserves the entire stated query family. Support counts and construction costs are recorded separately.

## Results

In every row the support may be capped by the original item count $m$.

| Problem and output | Support or guarantee | Construction and scope | Proof |
|---|---|---|---|
| Arbitrarily weighted Cayley spectral sparsification on any finite group $G$ | $O\!\left(\frac{\log^3(2\lvert G\rvert)}{\varepsilon^2}\right)$ generators | Deterministic polynomial time in the explicit permutation-matrix input; no weight-ratio dependence | [Theorem 1](manuscripts/arbitrary-group-cayley-sparsification.md) |
| A supplied $d$-dimensional unitary action of $G$ | $O\!\left(\frac{\log^2(2\lvert G\rvert)\log(2d)}{\varepsilon^2}\right)$ generator items | Support theorem for a supplied action; the regular-action bound also works simultaneously in every later representation; rational polynomial-bit construction is specified for explicit permutation matrices | [Representation corollary](manuscripts/arbitrary-group-cayley-sparsification.md) |
| Cayley generators after all $h$ correlated label deletions, at most $a$ labels per item | $O\!\left(\frac{\Gamma(h,a)\log^2(2\lvert G\rvert)\log(2\lvert G\rvert Q/\delta)}{\varepsilon^2}\right)$ | Randomized polynomial time in explicit group/input size; one common success event and fixed weights; for $h=1$, deterministic support $O\!\left(\frac{(a+1)\log^2(2\lvert G\rvert)\log(2\lvert G\rvert(L+1))}{\varepsilon^2}\right)$ | [Theorem 4](manuscripts/arbitrary-group-cayley-sparsification.md) |
| Whole subgroup-complement constraints | $O\!\left(\frac{\log\!\left(2[G:\bigcap_e H_e]\right)}{\varepsilon^2}\right)$ | Support existence and randomized construction polynomial in an explicit predicate table; arbitrary subgroups, including nonnormal ones | [Theorem 1](manuscripts/optimal-whole-subgroup-constraints.md) |
| Arbitrary affine coset-complement constraints | $O\!\left(\frac{\log(2\lvert G\rvert)}{\varepsilon^2}\right)$ | No common satisfying assignment required; explicit-table construction; optional exact total input weight | [Theorem 1](manuscripts/affine-constraints-over-arbitrary-finite-groups.md) |
| Arbitrary-arity group-derived Mal'tsev constraint violations over $A^n$ | $O\!\left(\frac{1+n\log\lvert A\rvert}{\varepsilon^2}\right)$ whole constraints | Each accepting relation is a subgroup coset; alphabet group may be nonabelian | [Corollary 2](manuscripts/affine-constraints-over-arbitrary-finite-groups.md) |
| Distances to an arbitrary received word in a subgroup code $C$ | $O\!\left(\frac{\log(2\lvert C\rvert)}{\varepsilon^2}\right)$ original coordinates | Preserves every codeword's weighted distance; does not perform decoding | [Group-code corollary](manuscripts/affine-constraints-over-arbitrary-finite-groups.md) |
| Sums of itemwise invariant Hilbert distances on a transitive $N$-point space | $O\!\left(\frac{\log(2N)}{\varepsilon^2}\right)$ whole metrics | Explicit-table construction under the stated numerical-access contract; optional exact total weight | [Theorem 1](manuscripts/transitive-metrics-and-group-alignment.md) |
| The same metric problem with orbit sizes $N_1,\ldots,N_k$ | $O\!\left(\frac{\min\{N,\log(2k!\prod_{j=1}^k N_j)\}}{\varepsilon^2}\right)$ | Symmetry branch uses the original distance table; unrestricted $N$ branch is the existing seminorm existence theorem | [Theorem 1](manuscripts/hilbert-metric-sums-with-few-orbits.md) |
| Two-anchor Euclidean alignment over a finite group $G$, including itemwise Bernstein transforms | $O\!\left(\frac{\log(2\lvert G\rvert)}{\varepsilon^2}\right)$ whole observations | Preserves every group alignment; norm losses are unsquared | [Corollary 2 and Section 4.1](manuscripts/transitive-metrics-and-group-alignment.md) |
| Coordinate-permutation alignment of vector or matrix pairs in dimension $d$ | $O\!\left(\frac{d\log(d+1)}{\varepsilon^2}\right)$ whole pairs | A specialization to $S_d$, also valid for signed permutations; no optimizer is asserted | [Sections 5.2–5.3](manuscripts/transitive-metrics-and-group-alignment.md) |
| Affine modular blocks over arbitrary binary-encoded $\mathbb Z_q$ | Existence $O(r/\varepsilon^2)$; compact randomized construction $O\!\left(\frac{r\log(2r/\varepsilon)}{\varepsilon^2}\right)$ | $r=\log_2\lvert H\rvert$, where $H$ is the subgroup generated by augmented rows; polynomial bit time without factoring; whole blocks remain atomic | [Theorem MB](manuscripts/affine-modular-blocks-and-sharp-modulus-dependence.md) |
| Closure-preserving rationalization of a unit-gap submodular rank | Exact rational rank at most $4R$, denominator $O(R)$, and identical zero marginals | $O(m)$ constant-precision weak evaluations plus one evaluation at precision $1/\operatorname{poly}(R)$ per value query | [Theorem 1](manuscripts/rational-quotient-ranks-from-weak-oracles.md) |

Here $Q=\sum_{j=0}^h\binom{L}{j}$ and $\Gamma(h,a)=\frac{(h+a)^{h+a}}{h^h a^a}$, with value one if either parameter is zero. The failure budget is clipped to the number of occurring labels $L$. $R$ is a supplied integer upper bound on the original submodular rank.

## Contract

| Field | Statement |
|---|---|
| **Objective and output** | Preserve each specified nonnegative objective within $1\pm\varepsilon$ using a subset of its original items with one nonnegative coefficient each. |
| **Time** | Cayley construction is polynomial in explicit group/action size. Gaussian subgroup and metric constructions are polynomial in an explicit query table under their separation/precision contract. Modular and rational-rank constructions are polynomial in compact binary input and $\varepsilon^{-1}$ with their stated oracle access. |
| **Space** | Support bounds count retained items. Input tables, output coefficient lengths, and algorithm workspace are separate; no independent workspace exponent is claimed. |
| **Parameters** | $m$ is the item count; group order, action dimension, orbit sizes, subgroup rank, label count, failure budget, modulus encoding, and accuracy are distinguished in the table. |
| **Model and representation** | Nonabelian groups and nonnormal subgroups are allowed. Every metric item must be invariant under the common action. Modular ranks use generated subgroups, not a presumed basis over a composite ring. |
| **Lower-bound scope** | Graph-cut instances force the joint $\log N/\varepsilon^2$ order in the stated large-$N$ regime. Powers-of-two moduli force $n\log q/\varepsilon^2$ for $\varepsilon\le1/4$ and $n\ge2\left\lceil(2\varepsilon)^{-2}\right\rceil$. Few-orbit lower bounds have their own orbit-size regime. |
| **Review status** | The [verification note](verify/README.md) records the proof scope, executable evidence and remaining conditions. No proof-assistant verification or external peer review is claimed. |
| **Source** | [Proofs](proof.md), [manuscript and reference map](sources.md), [analytic review](verify/README.md), and [exact checks](verify/README.md). |
