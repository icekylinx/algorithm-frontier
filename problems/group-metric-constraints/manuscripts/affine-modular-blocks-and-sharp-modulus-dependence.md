# Optimal support and compact sparsification for affine modular blocks

**Abstract.** For arbitrary binary-encoded modulus $`q`$, weighted affine blocks of congruences admit a relative-error summary on $`O(r/\epsilon^2)`$ whole original blocks, where $`r`$ is the logarithm of the subgroup generated by all augmented rows. A factorization-free randomized compact-input algorithm retains $`O(r\log(2r/\epsilon)/\epsilon^2)`$ blocks. Exact closure-preserving rationalization supplies the required value oracle. A multilevel cut construction over powers of two establishes $`\Omega(n\log q/\epsilon^2)`$ support in the stated joint regime.

## 1. Main theorem

Let $`q\ge2`$ be an arbitrary integer. A weighted input item $`e`$ consists of
```math
A_e\in\mathbb Z_q^{k_e\times n},\qquad
b_e\in\mathbb Z_q^{k_e},\qquad w_e\in\mathbb Q_{\ge0}.
```
Its penalty is
```math
B_e(x)=\mathbf1[A_ex\ne b_e\pmod q],
\qquad x\in\mathbb Z_q^n,
\tag{MB1}
```
where the vector inequality means that **at least one** equation in the block fails. A block contributes its weight once, regardless of how many internal equations fail. The number of equations and the variable support of a block are unrestricted.

Write
```math
W(x)=\sum_{e=1}^m w_eB_e(x),
\qquad
M_e=[\,A_e\ \ -b_e\,]\in\mathbb Z_q^{k_e\times(n+1)}.
```
Let $`H\le\mathbb Z_q^{n+1}`$ be the additive subgroup generated by all rows of all $`M_e`$, and put
```math
r=\log_2|H|,\qquad R=(n+1)\log_2q.
\tag{MB2}
```
If $`H=\{0\}`$, every penalty is zero and the empty output suffices. Otherwise $`1\le r\le R`$.

**Theorem MB.** For $`0<\epsilon<1`$, there are nonnegative coefficients $`c_e`$, on a subset of the original block indices, satisfying
```math
(1-\epsilon)W(x)
\le\sum_e c_e B_e(x)
\le(1+\epsilon)W(x)
\qquad\text{for every }x\in\mathbb Z_q^n.
\tag{MB3}
```
The following two bounds hold.

1. **Support existence.** One can retain
   ```math
   O\!\left(\min\{m,r/\epsilon^2\}\right)
      \subseteq O\!\left(\min\{m,R/\epsilon^2\}\right)
      \tag{MB4}
   ```
   whole original blocks. The supplied construction is polynomial in an explicitly listed finite-group query table, which can be exponential in the compact input dimension.

2. **Compact randomized construction.** In time polynomial in the binary input length and $`\epsilon^{-1}`$, without factoring $`q`$, one can retain
   ```math
   O\!\left(
         \min\left\{m,\frac{r\log(2r/\epsilon)}{\epsilon^2}\right\}
      \right)
      \subseteq
      O\!\left(
         \min\left\{m,\frac{R\log(2R/\epsilon)}{\epsilon^2}\right\}
      \right)
      \tag{MB5}
   ```
   whole original blocks, with success probability at least $`2/3`$.

There is no factor for the number of rows in a block. The rows contribute to input-reading and normal-form computation costs. Arbitrary rational weight ratios are allowed.

For $`q=2^k`$, the worst-case support scale in (MB4) is necessary: for $`0<\epsilon\le1/4`$ and $`n\ge2\lceil(2\epsilon)^{-2}\rceil`$, there are weighted instances requiring
```math
\Omega(n\log q/\epsilon^2)
\tag{MB6}
```
original items. These already use homogeneous scalar congruences on two variables per item. Thus the existence bound is jointly sharp in $`n,\log q,\epsilon`$ in this regime. This does not assert that the $`\log q`$ factor is necessary for prime $`q`$.

## 2. Optimal support from whole subgroup predicates

For each block, let $`J_e\le H`$ be generated by its augmented rows. Let $`\widehat H`$ be the character group of $`H`$; since $`H`$ is finite abelian, $`|\widehat H|=|H|`$.

Every $`y\in\mathbb Z_q^{n+1}`$ defines a character
```math
\chi_y(h)=\exp(2\pi i\,h\cdot y/q).
```
Define the annihilator subgroup
```math
K_e=\{\chi\in\widehat H:\chi(h)=1\text{ for all }h\in J_e\}.
\tag{MB7}
```
Then
```math
\mathbf1[M_ey\ne0\pmod q]
=\mathbf1[\chi_y\notin K_e].
\tag{MB8}
```

The whole-subgroup sparsification theorem in 30_optimal_whole_subgroup_constraints.md applies to arbitrary subgroups $`K_e`$ of a finite group and arbitrary nonnegative weights. It retains
```math
O(\log(2|\widehat H|)/\epsilon^2)=O(r/\epsilon^2)
```
original predicates, simultaneously for all characters. Restricting to $`y=(x,1)`$ proves (MB3)--(MB4). It suffices that every required $`y`$ gives a character; no particular parametrization of all characters is needed.

Each block remains one predicate. Sparsifying its scalar equations independently would preserve a different function.

The companion proof uses a Gaussian coset comparison, hereditary-section symmetrization, and partial coloring. With a complete query table, separation scans its inequalities. No compact polynomial-time implementation of that optimal-support construction is claimed. The ambient group $`\mathbb Z_q^{n+1}`$ gives the $`R`$-bound directly; passing to $`\widehat H`$ explains the sharper actual parameter $`r`$.

## 3. A logarithmic-order polymatroid on the original blocks

For $`S\subseteq[m]`$, put
```math
J(S)=\sum_{e\in S}J_e,\qquad
N_S=|J(S)|,\qquad f(S)=\log_2N_S.
\tag{MB9}
```
This function is normalized, monotone, and submodular. Indeed,
```math
J(S\cup T)=J(S)+J(T),\qquad
J(S\cap T)\subseteq J(S)\cap J(T),
```
and finite subgroup orders satisfy
```math
|J(S)|\,|J(T)|
=|J(S)+J(T)|\,|J(S)\cap J(T)|
\ge |J(S\cup T)|\,|J(S\cap T)|.
\tag{MB10}
```
Taking logarithms gives submodularity.

For $`S\subseteq T`$, a strict increase has
```math
f(T)-f(S)=\log_2[J(T):J(S)]\ge1,
\tag{MB11}
```
because a nontrivial finite index is an integer at least two. The total value is $`f([m])=r`$.

For a homogeneous query $`y`$, let
```math
Z_y=\{e:M_ey=0\pmod q\}.
```
This set is closed for $`f`$. All rows in $`J(Z_y)`$ annihilate $`y`$. If adding $`e`$ has zero $`f`$-marginal, the nested subgroups have the same order, so $`J_e\subseteq J(Z_y)`$. Hence every row of $`e`$ also annihilates $`y`$, giving $`e\in Z_y`$. Therefore $`[m]\setminus Z_y`$ is a quotient in Quanrud's terminology.

This argument uses additive subgroups and their orders, without assuming a field rank or a free-module basis over the composite ring.

## 4. Exact order computation without factoring the modulus

Set $`d=n+1`$. For a block subset $`S`$, form the full-rank integer lattice
```math
\mathcal L_S=
\mathrm{span}_{\mathbb Z}
\{\text{integer representatives of the augmented rows in }S\}
+q\mathbb Z^d
\subseteq\mathbb Z^d.
\tag{MB12}
```
Then $`J(S)=\mathcal L_S/q\mathbb Z^d`$. If $`D_S`$ is a square Hermite-normal-form basis of $`\mathcal L_S`$, then
```math
N_S=\frac{q^d}{|\det D_S|}.
\tag{MB13}
```
This quotient is an exact positive integer.

Standard polynomial-bit HNF algorithms compute the basis and determinant from the explicit rows and $`qI_d`$, without prime factorization. All group orders have at most $`O(d\log q)`$ bits.

Compute $`N_{[m]}`$ the same way. If it exceeds one, use the integer bound
```math
\overline R=\lceil\log_2N_{[m]}\rceil,
\qquad
r\le\overline R<r+1\le2r.
\tag{MB14}
```
It is found from the binary length, with a power-of-two check.

The values $`\log_2N_S`$ are generally irrational. Treating them as exact real inputs to a rational submodular-minimization algorithm would leave a bit-complexity gap. The next step resolves it while preserving precisely the same closed sets.

## 5. Rationalization and the compact algorithm

The rounding theorem in 35_rational_quotient_ranks_from_weak_oracles.md gives a deterministic exact rational value oracle $`g`$ that is normalized, monotone, and submodular, has the same zero marginals as $`f`$, has every positive marginal at least one, and satisfies
```math
g([m])=O(\overline R)=O(r).
```
Its values have a common dyadic denominator $`O(\overline R)`$ and polynomial bit complexity.

For the present integer-order oracle, its direct specialization is
```math
\phi(t)=t-\frac{t^2}{4\overline R},
\qquad
g(S)=4\,\mathrm{Round}
\bigl(\phi(\log_2N_S)\bigr),
\tag{MB15}
```
where the deterministic dyadic approximation has additive error at most $`\delta=1/(64\overline R)`$, is identical for identical integer $`N_S`$, and is exactly zero at $`N_S=1`$.

The mechanism is a positive submodularity slack gap. Set $`I=S\cap T`$, $`U=S\cup T`$, $`x=f(I)`$, $`a=f(S)-x`$, and $`b=f(T)-x`$. When $`a,b>0`$, both are at least one, and
```math
\begin{split}
&\phi(f(S))+\phi(f(T))-\phi(f(I))-\phi(f(U))\\
&\hspace{25mm}\ge \frac{ab}{2\overline R}
\ge\frac1{2\overline R}.
\end{split}
\tag{MB16}
```
This uses submodularity of $`f`$ and monotonicity of $`\phi`$ on $`[0,2\overline R]`$. Four rounding errors cost at most $`4\delta=1/(16\overline R)`$. If $`a=0`$ or $`b=0`$, monotonicity and submodularity force equality of the opposite nested pair too; the corresponding integer-order keys make their rounded values cancel exactly. A positive nested increase gives a $`\phi`$-increase at least $`1/2`$, so rounding and scaling by four leave its marginal greater than one.

Only $`O(\log\overline R)`$ bits of logarithmic precision are needed. The companion provides a convergent rational series and its bit analysis. Neither $`N_S`$ nor $`q`$ is factored.

Apply Quanrud's quotient-sparsification theorem to $`g`$, followed by the adaptive resparsification lemma in 27_adaptive_quotient_resparsification.md. Quanrud assumes that nonzero marginals are at least one, and does not require integer-valued $`g`$. The dyadic denominator in (MB15) must therefore **not** be multiplied into the rank.

The algorithm preserves every quotient of $`g`$ with support
```math
O(r\log(2r/\epsilon)/\epsilon^2).
```
Its ground-set elements are the original blocks. Since $`g`$ and $`f`$ have the same closed sets, all active sets $`[m]\setminus Z_y`$ are preserved. Restrict to $`y=(x,1)`$.

The resparsification companion gives the error-product and constant-confidence ledger. Its rational-weight analysis applies to the fixed-denominator oracle here: marginal numerators have polynomial bit length, and there are $`O(\log\log(2m))`$ passes. Every group-order query is an HNF computation. This proves (MB5) with compact randomized polynomial bit time and no factoring oracle.

## 6. A matching lower bound for powers of two

### 6.1 The cut-support ingredient

Let $`0<\eta\le1/2`$, $`s=\lceil\eta^{-2}\rceil`$, and $`B\ge s`$. Every nonnegative reweighting of original edges preserving all cuts of unweighted $`K_{s,B}`$ within $`1\pm\eta`$ uses
```math
\Omega(B/\eta^2)
\tag{MB17}
```
edges.

Here is a proof. Write the output as an $`s\times B`$ matrix $`W`$, put $`E=W-\mathbf1`$, and let $`t_j`$ be the number of nonzero entries in column $`j`$. The total-weight cut and arbitrary sign cuts imply
```math
|\sigma^\top E\tau|\le3\eta sB
\quad(\sigma\in\{\pm1\}^s,\ \tau\in\{\pm1\}^B).
```
Choose the maximizing $`\tau`$ for each $`\sigma`$, then average over independent signs $`\sigma`$. The $`L_1`$ Khintchine inequality gives
```math
\sum_j\|E_{\cdot j}\|_2\le3\sqrt2\,\eta sB.
```
A singleton right-vertex cut gives degree at least $`(1-\eta)s`$, hence
```math
\|E_{\cdot j}\|_2
\ge\frac{(1-\eta)s}{\sqrt{t_j}}-\sqrt s.
```
If $`t=\sum_jt_j`$, Jensen's inequality gives
```math
t\ge
\frac{(1-\eta)^2sB}
     {(1+3\sqrt2\,\eta\sqrt s)^2}
=\Omega(B/\eta^2).
\tag{MB18}
```
This is the inherited cut-support obstruction also recorded in 28_exact_label_cut_and_matroid_quotient_sparsification.md.

### 6.2 Independent valuation levels

Let $`q=2^k`$, $`\eta=2\epsilon\le1/2`$, and
```math
s=\lceil(2\epsilon)^{-2}\rceil,\qquad B=n-s\ge s.
```
Use the vertices of $`K_{s,B}`$ as the $`n`$ modular variables. For every edge $`uv`$ and each $`j=0,\ldots,k-1`$, introduce the scalar block
```math
2^j(x_u-x_v)\equiv0\pmod{2^k}
```
with weight $`3^j`$.

For $`0\le\ell\le k`$, restrict to
```math
x_v=2^{k-\ell}z_v\pmod{2^k},
\qquad z_v\in\{0,1\}.
\tag{MB19}
```
At $`\ell=0`$ this is the all-zero query. Precisely the crossing edges at levels $`j<\ell`$ violate their equations. Their total weight is
```math
W_\ell=\sum_{j<\ell}3^j=\frac{3^\ell-1}{2}
```
times the cut size of $`K_{s,B}`$.

For any claimed sparsifier, let $`G'_j`$ consist of its retained original items at level $`j`$, with their output coefficients. Equation (MB3) gives
```math
\mathrm{cut}_{\sum_{j<\ell}G'_j}(z)
\in(1\pm\epsilon)W_\ell
\mathrm{cut}_{K_{s,B}}(z)
\quad\text{for every }z.
\tag{MB20}
```
Subtract the prefix equations for $`\ell=j+1`$ and $`\ell=j`$. The error bounds add:
```math
\begin{split}
\left|
\mathrm{cut}_{G'_j}(z)
-3^j\mathrm{cut}_{K_{s,B}}(z)
\right|
&\le\epsilon(W_{j+1}+W_j)
\mathrm{cut}_{K_{s,B}}(z)\\
&\le2\epsilon\,3^j\mathrm{cut}_{K_{s,B}}(z).
\end{split}
\tag{MB21}
```
Thus $`3^{-j}G'_j`$ is a $`1\pm2\epsilon`$ cut sparsifier separately at every level. By (MB17), each level retains $`\Omega(B/\epsilon^2)`$ items. The levels have disjoint original item identities, so the total is
```math
\Omega(kB/\epsilon^2)=\Omega(n\log q/\epsilon^2).
```

All coefficients and input weights have $`O(k)=O(\log q)`$ bits. The argument allows arbitrary nonnegative output coefficients. It already uses single-row, two-variable, homogeneous blocks.

The level-zero rows of the connected bipartite graph generate the entire sum-zero subgroup of $`\mathbb Z_q^n`$; the homogenizing coordinate is zero. Thus this family has $`|H|=q^{n-1}`$ and $`r=(n-1)\log_2q`$, so the lower bound also matches the actual-parameter order $`r/\epsilon^2`$.

## 7. Mixed moduli

Blocks may also use a different modulus on each row. For a row
```math
a\cdot x\equiv b\pmod{q_i},
```
compute $`Q=\mathrm{lcm}_i q_i`$ by gcd operations and replace its augmented row by
```math
\frac{Q}{q_i}(a,-b)\pmod Q.
\tag{MB22}
```
The original congruence holds exactly when this scaled row annihilates $`(x,1)`$ modulo $`Q`$. Whole-block penalties are unchanged.

View assignments modulo $`Q`$. Apply (MB4)--(MB5) to the subgroup generated by the scaled augmented rows; the coarse parameter is $`(n+1)\log_2Q`$. Since $`\log Q\le\sum_i\log q_i`$, all encodings and HNF computations remain polynomial in the original input length. No modulus is factored.

## 8. Related work

- **Khanna--Putterman--Sudan, _Efficient Algorithms and New Characterizations for CSP Sparsification_, STOC 2025.** Theorem 5.19 already gives arbitrary weighted scalar codes over $`\mathbb Z_q`$ compact randomized sparsifiers of size $`\widetilde O(n\log^2q/\epsilon^2)`$, in time polynomial in $`mn\log q/\epsilon`$. Section 6 treats finite abelian group codes. Modular code sparsification and affine homogenization are established models. Primary source: <https://arxiv.org/html/2404.06327v2>.

- **Quanrud, _Quotient sparsification for submodular functions_, SODA 2024.** Theorem 1.1 permits real-valued normalized monotone submodular functions with nonzero marginals at least one, and gives $`O(r\log(mr)/\epsilon^2)`$ support. The new implementation step here is the exact rational oracle preserving the closures of logarithmic subgroup order; a bare real-log oracle would not establish polynomial bit time. Primary manuscript: <https://kentq.s3.amazonaws.com/submodular-sparsification.pdf>.

- **Brakensiek--Guruswami--Putterman, _Multiplicative error set system sparsification: A simpler proof via chain length contraction_, May 2026.** Theorem 1.2 has an extra $`\log^2(d/\epsilon)(\log\log(d/\epsilon))^2`$ factor in chain length $`d`$. Here $`d\le r`$: intersections of closed sets remain closed, so every strict chain in the union-closure of the active sets reverses a strict chain of closed sets. Each strict inclusion between closed sets increases $`f`$ by at least one. Their Conjecture 5.1 asks for $`O(d/\epsilon^2)`$ in general. The subgroup theorem used here does not settle that conjecture for arbitrary set systems. Primary source: <https://arxiv.org/abs/2605.01508>.

- **Kannan--Bachem, _Polynomial Algorithms for Computing the Smith and Hermite Normal Forms of an Integer Matrix_, 1979.** This supplies the standard polynomial-bit HNF input: <https://doi.org/10.1137/0208040>.

The proof combines optimal-support whole subgroup sparsification, exact closure-preserving rationalization, and the valuation-level lower bound. It gives worst-case optimal $`O(n\log q/\epsilon^2)`$ support and a compact polynomial-time construction within one logarithm, uniformly for arbitrary affine modular blocks. In the scalar case, (MB5) replaces KPS's displayed quadratic $`\log q`$ dependence by linear $`\log q`$ times the explicit factor $`\log(n\log q/\epsilon)`$. It does not claim to beat every specialized scalar or fixed-modulus algorithm in every regime.
