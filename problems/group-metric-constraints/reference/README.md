# Exact whole-coset compiler

[Implementation](coset_compiler.py) · [Realization proof](../manuscripts/reference-coset-compilation.md) · [Independent checker](../verify/check_coset_compiler.py)

The compiler preserves every original coset predicate inside one common
implicit wreath product. It supports arbitrary explicitly tabulated finite
groups, including nonabelian groups and nonnormal subgroups. It supplies
subgroup generators, exact membership and an explicit-query verifier for
proposed whole-item coefficients. It does not choose sparse coefficients.

```python
from fractions import Fraction
from coset_compiler import Group, Coset, compile_cosets, verify_coefficients

group = Group(tuple(tuple((a+b) % 6 for b in range(6)) for a in range(6)))
items = (Coset(1, (2,)), Coset(0, (3,)), None)
compiled = compile_cosets(group, items)
for g in range(6):
    for item in compiled:
        assert item.accepts_original(g) == item.contains(group.query(g))
assert verify_coefficients(group, items, (1, Fraction(2, 3), 2), (1, 1, 1), 0)
```

`Group(table, identity=0)` copies and validates the multiplication table,
identity, inverses and associativity. Elements are original integer table
indices; a nonzero identity index is allowed. A `Coset(anchor, generators)`
means the left coset of the subgroup generated by the listed elements.
`None` is an empty accepting set. Empty generator lists specify the trivial
subgroup, so they are distinct from an empty accepting set. Parallel items
retain distinct original positions.

A compiled item's `generators()` describes its whole subgroup. `contains`
accepts `(x, y, parity)` triples in the common wreath group. The implicit
ambient operations do not allocate a new multiplication table. `query(g)`
is one fixed odd triple for every original query, independent of the item.
It is an embedding of queries, not a group homomorphism.

`verify_coefficients` reads original descriptors and checks all original
queries with exact integers/Fractions. It rejects negative coefficients,
inexact numbers, Boolean scalars and invalid error parameters. Setting
`exact_total=True` additionally checks original total weight, including
identically zero predicates. Its success certifies the supplied coefficients;
it does not establish that they have small support or that a sampler succeeds.
The predicate family, table and numeric encoding costs are charged explicitly.

The established algebraic construction is credited in the proof. No third-party
code is copied, and no analytic partial-coloring implementation is included.
