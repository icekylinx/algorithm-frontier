# Verification and scope

The [main proof](../proof.md) and [certified realization](../reference-realization.md)
separate the complete approximation theorem from the executable local gate.

## Mathematical review

Internal review covers the complete bounded-certificate theorem: exact
budgeted unit tests on original eligible owner/type pairs, original minimal
failure extraction, guarded common-basis extension, every forced seed and
failed branch, scenario-intersection support separation, higher integer
quota recovery on integral maximum-total faces, one-sided target search
and streamed whole-ground conversion. The width-one exception and fixed-
tradeoff exact algebraic comparisons are retained. The combined exponential
base is the maximum of unit and positive-quota costs.

The Boolean-cap matroid proof, weighted augmentation mapping, exchange
potential optimality certificates and cardinality cut have explicit
arguments in the realization note. The weighted augmentation and cycle
characterization use the precisely identified primary theorem. General
rank-only Boolean-cap tests retain paid submodular minimization; the
complete-table adapter charges its own larger explicit input.

## Executable evidence

```sh
python3 problems/robust-bounded-certificates/verify/check_bounded.py
python3 tools/verify_profile_certificates.py
```

The [reference](../reference/README.md) supplies polynomial weighted matroid
intersection, native budgeted unit tests, exact rejection records and the
bounded local gate. Its independent checker covers:

- 1,978 exact weighted cardinality optima against exhaustive common-
  independent-set enumeration, including underfull maximum-cardinality
  cuts, signed rational prices, zero ties, loops and a required exchange.
- 698 native budgeted polymatroid assignment optima from independently
  enumerated owner/type choices and every original rank inequality.
- 4,492 bounded-gate cases checked against original selected bases,
  including all single forbidden-set families on up to four players,
  all ranks/seeds and three supplied widths, plus native nonuniform
  binary-represented player-matroid instances.
- 63 valid inclusion-minimal wider failure certificates; every single
  deletion is checked feasible in the original scenario.
- 124 integrations passing actual budgeted resource-unit witnesses to both
  the bounded gate and the existing Fibonacci width-two implementation.
- Five forged-certificate rejections, five malformed inputs, costs/ranks
  with hundreds of bits, complete node accounting, and verification of an
  over-budget minimum-cost record with the optimizer disabled.

The native assignment comparator imports no backend formulation, weighted
optimizer or dual-basis construction. It tests original resources and
actual costs directly. Generic matroid tests share the same original
independence/rank oracles, as their model requires; their exhaustive
comparators do not call the intersection or gate algorithms. The verifier
checks canonical record types, original exchange inequalities and rank
cuts rather than trusting constructor paths. Finite examples do not prove
the general weighted augmentation theorem or validate arbitrary user oracles.

The existing profile checker separately certifies integer-quota arithmetic
for `d=2,...,30` and every `d<K<=399` (11,107 cases), including the small-
target one-unit identities. It does not execute higher-quota scenario LPs
or integral polymatroid recovery.

## Model and implementation boundaries

The exact unit scenarios use original ranks, masks, assignment prices and
one nonnegative budget each. No binary multiplicity is expanded into unit
records. Width violations are separate structural outcomes; exhausted
failure remains sound outside the promise. The unrestricted two-scenario
hardness result has a different scope and supplies no optimal base here.

The implementation realizes the weighted/unit/local-gate interfaces and
can supply actual callbacks to the width-two backend. Higher-quota service
LPs, integral quota recovery, integer target search and the streamed global
wrapper remain complete mathematical algorithms rather than implemented
features of this reference. Their exact rational LP, SFM and integral
polymatroid-intersection primitives are paid theorem dependencies, not
unproved interfaces created by missing software.

The [source map](../sources.md) identifies these dependencies. Repository
checks validate links, notation and generated surfaces rather than
mathematical correctness. External peer review and proof-assistant
verification are not claimed.
