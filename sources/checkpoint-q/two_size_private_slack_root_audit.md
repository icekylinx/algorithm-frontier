# Root audit: private-slack rank deficit for two-size scheduling

**25 October 2026. Internal independent mathematical review.**

The root reviewer read D1--D23 of
`two_size_makespan_private_slack_deficiency.md`. The exact 5/3 result,
its target-dependent rank parameter, finite-rank quota variants and
fine-unit variants pass this review. The findings below record the
points that are necessary to avoid overstating this parameter transfer.

## 1. Private coordinates can be inserted without resource contraction

For a polymatroid f, let `sigma_p=f(P)-f(P-p)`. Submodularity gives
`f(S+p)-f(S) >= sigma_p` whenever p is outside S. Consequently every
feasible vector on the complement of a set F0 remains feasible after
inserting at most sigma_p units at each member of F0. Apply the
inequality successively to members of an arbitrary test subset.

This proof uses the minimum possible marginal of a coordinate. Merely
being independently feasible at F0, or having a large singleton rank,
would not justify the same insertion. The manuscript uses exactly the
minimum-marginal hypothesis needed here.

## 2. An arbitrary greedy commitment retains the full target promise

Let F0 be a maximum player-matroid independent subset of the private
set. An optimum basis I* spans the original player matroid, so its
image spans the contraction by F0. Some subset J of `I* minus F0` is
a basis of that contraction. Restriction of the promised recipient
allocation to J still gives K units per member and is feasible in the
recipient polymatroid restricted to the remaining coordinates.

It is unnecessary for F0 to belong to I*, or to have K private units.
F0 only needs the output quota b. After solving the residual full-K
promise, the private-coordinate lemma inserts those b units. The player
rank is exactly `h-r_M(F)`. Rank zero bypasses the inner search and
uses the same insertion directly.

## 3. The scheduling private set is computed correctly

For the c-box-restricted small-job rank g, its complement dual is
`f(S)=c|S|+g(P minus S)-g(P)`. Its private marginal at p is
`c-g({p})=c-min(c,f_s({p}))`. Thus the output requirement b is met
privately precisely when `f_s({p}) <= c-b`.

In the hard target interval `a <= T < 2a`, the large-job Boolean
matroid is independent of T. The small promise is
`K=c-floor((T-a)/u)`, and a target-feasible schedule provides at least
K dual units on a large-job basis. All capped total-rank tests must
pass before using these bases. Their failure is genuine target
infeasibility; failure of the requested rank budget is different.

## 4. The cap is monotone and the optimization direction is sound

For `b=ceil((c-d)/3)`, the private-set threshold is
`c-b=floor((2c+d)/3)`. Both c and d are nondecreasing in T, so the
private set expands and its rank deficit decreases. Defining the cap
to hold automatically from `T=2a` makes it globally monotone.

Every change is on the rational grid generated by a and u. The first
cap-feasible target Theta is attained. The joint feasible/capped domain
therefore starts at `max(OPT,Theta)` on the same grid.

Any failed target is below this joint threshold, whether failure came
from original infeasibility or the cap. Binary search may still use a
successful approximate target below OPT. It preserves a failed lower
and successful upper endpoint; grid adjacency gives a final successful
target no larger than the joint threshold. This proves the stated
`(5/3) max(OPT,Theta)` guarantee without requiring monotone success.

The readily constructed upper endpoint `max(V,2a)` is both feasible
and capped. A failed Boolean rank below 2a implies `OPT >= 2a`, so
the automatic easy branch does not remove a feasible optimum.

## 5. Exact and positive-error quota refinements

The exact inequality

\[
(3r-2)b<rK+2r-1
\]

is equivalent, for integral b, to

\[
b\le\left\lfloor\frac{rK+2r-2}{3r-2}\right\rfloor.
\]

A quota certified at rank k is certified at every positive rank at
most k, since `(r-1)/r` is monotone. The formula for `c-b_k(c-d)`
has nonnegative coefficients of c and d, so the stronger private cap
is also monotone. It must be recomputed for that stronger quota.

The k=2 quota is `ceil(K/2)`, yielding a 3/2 bound in both hard and
easy branches. For k at least three, K=3 still allows only one unit
under this certificate, so the unqualified exact-quota coefficient
does not improve beyond 5/3. The note correctly retains this discrete
limitation.

For positive error, the unit growth proof needs a sufficiently large
K. The supplied condition `u <= eta T/18` is sufficient and must be
enforced at every queried target. Under the corresponding OPT promise,
restricting target search to that range loses no optimum. The displayed
quasipolynomial dependence is not asserted without that size promise.

## Verdict and comparator

The private-slack parameter is a rigorous improvement of the exponent
for the specified oracle polymatroid model. It can be small while the
total number of large units is large. It does not give an unconditional
polynomial-time 5/3 algorithm, and cap rejection must not be described
as original target infeasibility. Public two-size numerical factors
and the distinction between estimation and schedule construction remain
as recorded in the main note's cited baseline discussion.
