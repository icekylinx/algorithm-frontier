## Parameter conventions

H is the complete binary input and paid polynomial oracle work.
H_epsilon includes the full rational accuracy encoding.
T is an original integer numeric target or target sum.
Rational scaling changes T explicitly; it is not identified
with 1/epsilon. Every mandatory base keeps its original total.

Tight numeric exponents refer to general rank-oracle matroids.
The inverse-accuracy upper/lower gap remains open.

Some allocation transfers refer to Q's earlier profile
interfaces. Those dependencies are named rather than
repacked. New exact scalar and mixed-target proofs include
their recovery arguments.

Complete internal reviews support the included claims.
Detailed working review logs are not duplicated here.
