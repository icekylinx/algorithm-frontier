# Formula image attribution

These self-contained SVG files are generated from this repository's exact
TeX sources with MathJax 3.2.2. Embedded TeX-font glyph paths retain the
MathJax Consortium's copyright notice:

Copyright (c) 2018–2022 The MathJax Consortium.

MathJax is licensed under Apache License 2.0; its distributed license is
preserved in [LICENSE.mathjax](LICENSE.mathjax). The repository's author
attribution and licenses govern its mathematical text and proof sources.

The [pinned renderer](../../tools/math-renderer/package-lock.json) is an
authoring dependency. Reading the images needs no JavaScript, external font
or mathematical renderer. [manifest.json](manifest.json) binds every used
image to its exact source and generated bytes.
